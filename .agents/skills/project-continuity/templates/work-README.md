# Durable Handoffs (Optional)

Use `items/` only for meaningful unfinished outcomes that must survive a session, agent, person, or tool boundary and are not already tracked in an issue tracker, orchestrator Task, or authoritative project record.

A Work Item is a portable handoff note, not a general backlog, scheduler, or replacement for Orca Tasks. Do not create one for every coding task. Keep one active writer per item and preserve exact work products at their authoritative paths.

The YAML status describes the handoff record, not live Worker or issue status. `depends_on` is informational and does not schedule work.
